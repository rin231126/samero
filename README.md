# SAMERO — Pixel AI Studio

Independent Windows desktop workspace for AI-assisted development, Codex project management and Pixel Studio.

This repository is reserved for the public static product website. Upload the complete website bundle with `index.html`, `en.html`, `assets/` and `downloads/` at the repository root, then enable Settings → Pages → Deploy from a branch → main → /(root).

Release: 1.9.0-studio-rc1. The unsigned Windows executable is a release candidate; real Windows and authenticated Codex testing remain incomplete. No personal workspace or credentials should be committed.
